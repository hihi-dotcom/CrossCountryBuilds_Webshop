Webshop REST API

Swagger-stílusú, statikus dokumentáció (backend & admin végpontok)

Áttekintés

Ez a dokumentum a webshophoz tartozó REST API végpontjait írja le. A mezőnevek, útvonalak és objektumok nevei angolul szerepelnek, a leírások magyarul, röviden és érthetően fogalmazva.

Válaszok formátuma: alapértelmezetten JSON. Hibák esetén általában egy state mezőt tartalmazó objektum érkezik ("ok" vagy "err", illetve egyéb leíró üzenetek).

Nyilvános és felhasználói végpontok

Termékek
GET /api/products?from=0&to=13 Termékek listázása (főoldal)

Az endpoint pagináltan listázza a webshop termékeit. A from és to query paraméterek a visszaadott termékek sorszámtartományát határozzák meg (0-tól indexelve, mindkettő beleértve).

Query paraméterek
NévTípusKötelezőLeírás
from integer igen Kezdő index (0-tól), ettől a sorszámú terméktől kezdjük a listázást.
to integer igen Záró index, eddig a sorszámig listázzuk a termékeket (beleértve).
Válasz (200 – OK)

Egy JSON tömb, amely termékobjektumokat tartalmaz.

{
  "products": [
    {
      "name": "string",
      "category": "string",
      "manufacturer": "string",
      "description": "string",
      "picture": "string",
      "price": 0
    }
  ]
}
GET /api/products Termékek szűrése

Szűrt terméklista lekérése a megadott feltételek alapján. A backenden csak azok a termékek kerülnek visszaadásra, amelyek tulajdonságai megfelelnek a query paramétereknek.

Példa kérésre
GET /api/products?name=productname&category=category
Lehetséges query paraméterek
NévTípusKötelezőLeírás
name string nem Termék neve (részleges egyezés is lehet).
category string nem Termékkategória szűrő.
Válasz (200 – OK)

Ugyanaz a struktúra, mint a sima terméklista esetén.

Rendelés / Kosár
PUT /api/order Rendelés leadása a kosár tartalmából

A végponttal a kosár tartalmából rendelés hozható létre. A frontenden a „Rendelés befejezése” gombra kattintva egy JSON objektum kerül elküldésre a rendelés tételeivel, valamint a kiválasztott szállítási és fizetési móddal.

Kérés törzse (Request body)
{
  "products": [
    {
      "product_name": "string",
      "product_number": 1
    },
    {
      "product_name": "string",
      "product_number": 2
    }
  ],
  "shipping_method": "string",
  "payment_method": "string"
}
Válasz (200 – OK)

A backend visszajelzést ad a rendelés sikerességéről. Ha egyes termékek időközben elfogytak, azokat külön listában adja vissza, hogy a felhasználó módosíthassa a kosarat. 

{
  "state": "ok" | "err",
  "out_of_stock": [
    "product_name_1",
    "product_name_2"
  ]
}
Felhasználói fiók és hitelesítés
POST /api/login Bejelentkezés

Bejelentkezés a felhasználói fiókkal. A frontend a bejelentkezési űrlap adataiból JSON objektumot épít, és elküldi a backendnek.

Kérés törzse
{
  "email": "string",
  "password": "string"
}
Válasz (200 – OK)
{
  "state": "ok" | "err"
}
PUT /api/registration Regisztráció

Új felhasználói fiók regisztrációja. A frontend a regisztrációs űrlap mezőit JSON objektumba tömöríti, és elküldi a backendnek.

Kérés törzse
{
  "email": "string",
  "name": "string",
  "password": "string"
}
Válasz (200 – OK)

A válasz egy állapotot leíró szöveg a state mezőben.

{
  "state": "username is already in use"
          | "there is an account registered from this email"
          | "ok"
}
GET /api/user Saját felhasználói adatok lekérése

A bejelentkezett felhasználóhoz tartozó adatok lekérése. A végpont egy JSON objektumot ad vissza a felhasználó törzsadataival és címinformációival.

Válasz (200 – OK)
{
  "username": "string",
  "email": "string",
  "delivery_address": "string",
  "billing_address": "string"
}
PATCH /api/username, /api/email, /api/delivery_address, /api/billing_address, /api/password Saját adatok módosítása

A végpontok segítségével egyenként módosíthatók a felhasználó adatai. A frontend a „Módosítások mentése” gombra kattintva küld PATCH kérést, a módosított értékkel.

Kérés törzse
{
  "data": "string"
}
Válasz (200 – OK)
{
  "state": "ok" | "err"
}
GET /api/appointments Szerviz időpontok lekérése

A végpont a szabad szerviz/behozatali időpontokat adja vissza JSON formátumban. A frontend ezeket jeleníti meg a felhasználó számára, aki innen választhat időpontot.

Válasz (200 – OK)

A pontos struktúra implementációfüggő; tipikusan id + dátum/idő mezők.

PATCH /api/appointment Időpontfoglalás létrehozása

Miután a felhasználó kiválasztott egy időpontot és leírta a problémát, a frontend ezen a végponton keresztül küldi el az időpontfoglalás adatait a backendnek.

Kérés törzse
{
  "date": "string",
  "description": "string"
}
Válasz (200 – OK)

Visszaadja az időpontfoglalás állapotát.

{
  "state": "ok" | "err"
}
POST /api/recovery Jelszó visszaállítás kezdeményezése

Jelszó-visszaállítás indítása. A felhasználó e-mail címe alapján a rendszer elindítja a visszaállítási folyamatot (pl. e-mail küldése egy linkkel).

Kérés törzse
{
  "email": "string"
}
PATCH /api/recovery Új jelszó beállítása

A jelszó-visszaállítás folyamatának második lépése. A felhasználó új jelszavát küldi el a backendnek, amely aktualizálja az adott fiók jelszavát.

Kérés törzse
{
  "password": "string"
}
POST /api/authentication Hitelesítés (User vagy error)

Általános hitelesítési végpont. Siker esetén a felhasználó adatait tartalmazó objektumot ad vissza, hiba esetén error-t.

Kérés törzse
{
  "email": "string",
  "password": "string"
}
Válasz (200 – OK)
{
  "user": {
    "id": 1,
    "name": "string",
    "delivery_address": "string",
    "billing_address": "string",
    "email": "string"
  }
  // vagy hiba esetén error objektum
}

Admin végpontok

Admin – Termékek
GET /api/products?from=0&to=13 Termékek listázása admin felületen

Ugyanaz a logika, mint a nyilvános listázásnál, de admin nézetben a termékek szerkeszthetők, törölhetők.

PATCH /api/admin/product Termék módosítása

Egy meglévő termék módosítása a termékazonosító alapján. A kérés törzsének kötelező része a termék azonosítója, a további mezők a módosítandó értékek.

Kérés törzse
{
  "id": 1,
  "name": "string",
  "category": "string",
  "manufacturer": "string",
  "description": "string",
  "picture": "string",
  "price": 0
}
POST /api/admin/product Új termék létrehozása

Új termék létrehozása az adatbázisban. Az eredeti leírás szerint a termék üres értékekkel jön létre, amelyet később a módosító végponttal lehet kitölteni.

DELETE /api/admin/product Termék törlése

Egy megadott termék törlése az adatbázisból. A kérés törzsében a törlendő termék nevét kell megadni.

Kérés törzse
{
  "product_name": "string"
}
Admin – Felhasználók
GET /api/admin/users?from=0&to=12 Felhasználók listázása

Az adott sorszámtartományba eső felhasználók adatainak lekérése.

Válasz (200 – OK)
[
  {
    "id": 1,
    "name": "string",
    "delivery_address": "string",
    "billing_address": "string",
    "email": "string"
  }
]
DELETE /api/admin/users Felhasználó törlése

Egy felhasználó törlése a látogatók/ felhasználók táblából azonosító alapján.

Kérés törzse
{
  "id": 1
}
Admin – Megrendelések
GET /api/admin/orders?from=0&to=12 Megrendelések listázása

A paraméterben megadott sorszámtartományba eső megrendelések lekérése JSON tömb formájában.

Válasz (200 – OK)
[
  {
    "id": 1,
    "user": {
      "id": 1,
      "name": "string",
      "delivery_address": "string",
      "billing_address": "string",
      "email": "string"
    },
    "state": "string",
    "items": [
      {
        "name": "string",
        "category": "string",
        "manufacturer": "string",
        "description": "string",
        "picture": "string",
        "price": 0,
        "quantity": 1
      }
    ],
    "shipping_method": "string",
    "payment_method": "string"
  }
]
PATCH /api/admin/orders Megrendelés állapotának módosítása

Egy megrendelés állapotának frissítése (pl. „függőben”, „feldolgozás alatt”, „teljesítve” stb.). A módosítandó megrendelést azonosító alapján választjuk ki.

Kérés törzse
{
  "id": 1,
  "state": "string"
}
DELETE /api/admin/orders Régi megrendelés törlése

Egy már régi vagy archiválandó megrendelés törlése az adatbázisból, megrendelés azonosító alapján.

Kérés törzse
{
  "id": 1
}
Admin – Időpontfoglalások (Szerviz)
GET /api/admin/appointment?from=0&to=12 Időpontfoglalások listázása

Beérkezett időpontfoglalások lekérése JSON tömb formájában. Az URL-ben lévő from és to sorszám paraméterek határozzák meg, hogy mely foglalások kerüljenek visszaadásra.

Válasz (200 – OK)
[
  {
    "id": 1,
    "username": "string",
    "user_email": "string",
    "name": "string",
    "dropoff_time": "string",
    "pickup_time": "string",
    "description": "string"
  }
]
PATCH /api/admin/appointment Időpontfoglalás módosítása

Egy meglévő szerviz időpontfoglalás adatainak módosítása. A törzsben az azonosítón kívül minden szükséges mező megadható.

Kérés törzse
{
  "id": 1,
  "username": "string",
  "user_email": "string",
  "name": "string",
  "dropoff_time": "string",
  "pickup_time": "string",
  "description": "string"
}
DELETE /api/admin/appointment Időpont törlése

Egy már megtörtént vagy törlendő időpontfoglalás eltávolítása. A törléshez csak az időpont azonosítója szükséges.

Kérés törzse
{
  "id": 1
}
